# CGPA Calculator

A simple **CGPA Calculator** developed using **C++** as part of my **CodeAlpha Internship**.

## Project Description

This project is a basic C++ program that calculates a student's GPA based on the grades and credit hours of their courses.

The program takes the number of courses, then asks the user to enter the grade and credit hours for each course. After that, it calculates the total credit hours, total grade points, and GPA.

## Features

* Enter the number of courses
* Enter the grade for each course
* Enter the credit hours for each course
* Calculate total credit hours
* Calculate total grade points
* Calculate GPA
* Display the final results

## Technologies Used

* C++
* C++ Standard Library
* Basic Programming Concepts

## How It Works

The program uses the following formula:

**Grade Points = Grade × Credit Hours**

Then:

**GPA = Total Grade Points ÷ Total Credit Hours**

### Example

If a student has:

| Course   | Grade | Credit Hours |
| -------- | ----: | -----------: |
| Course 1 |   3.5 |            3 |
| Course 2 |   3.0 |            3 |
| Course 3 |   4.0 |            2 |

The program calculates the total credit hours and grade points, then displays the GPA.
